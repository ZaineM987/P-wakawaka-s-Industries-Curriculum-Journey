Educator Notes: Pedagogical Framework

This introductory application for 5-to-6-year-old learners has been specifically designed in alignment with Cognitive Load Theory (CLT), pioneered by educational psychologist John Sweller.

To ensure complex topics like global macro-industries remain consumable for Early Childhood Education (ECE) in New Zealand, the app implements the following cognitive load management strategies:

  • Minimizing Extraneous Load: The interface removes non-essential text and distracting animations. Each screen presents only one isolated task with 3 highly distinct choices.
  • Managing Intrinsic Load: Complex industry definitions are distilled into single, relatable "Kid-Friendly Concepts" (e.g., "Giant invisible libraries in the sky" for Cloud Computing).
  • Modality Effect: The inclusion of an explicit Text-to-Speech (TTS) feature prevents working memory overload by offloading reading demands, allowing early readers to process information via dual channels (auditory instruction + visual symbols).

By leveraging Sweller's principles, children can construct foundational schemas regarding societal infrastructures without becoming overwhelmed.
